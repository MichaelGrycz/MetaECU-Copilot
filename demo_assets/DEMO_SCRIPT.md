1. Regenerate all artifacts first: `python demo_assets/generate_demo_assets.py`
2. Record the desktop app (`dist/MetaECU_Copilot.exe`) or the Modal URL (`https://michaelgrycz--metaecu-copilot-web.us-east.modal.run`) — window 1920×1080, audio ON (engine rev, spool, alarm, relay click).
3. Click `▶ 60s JUDGE TOUR` to run the fully automated, hands-free on-camera demonstration, or manually interact with the gauges.
4. Keep the rejection moment uncut — it is the undeniable star of the show.
5. End card shows the public Modal Live Product URL and the GitHub repo.
